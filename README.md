# NZPC 2026

Post-contest archive of solutions (including "practice") from the New Zealand Programming Contest (NZPC) 2026. This repository is kept for reference and does not represent a polished submission, although an attempt has been made to do so in `rewritten/`.

## Contents

- `a.py` through `k.py`: contest problem solutions as submitted (and accepted) during the contest
- `practice/`: "practice" problems solved before the official contest
- `rewritten/`: clearer rewrites of solutions + ones we did not attempt during the contest
- `*.bak`: earlier versions that did not pass any/all test cases

(Obviously), the scripts have no external dependencies.
